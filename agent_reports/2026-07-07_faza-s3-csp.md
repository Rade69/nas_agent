## Problem
`index.html` nije imao CSP; nije bilo `onHeadersReceived` CSP-a. XSS u rendereru (npr. kroz prikaz sadržaja koji Ricky čita) je — iako je Node pristup već zatvoren sa contextIsolation+sandbox — mogao slobodno da eksfiltrira podatke na proizvoljan domen ili izvrši inline script. CSP je defense-in-depth sloj koji je nedostajao.

## Ključna Electron specifičnost
Prod se učitava preko `file://` (`window.cjs` `loadFile(dist/index.html)`). `session.webRequest.onHeadersReceived` **ne okida za file:// dokumente**, pa response-header CSP ne bi pokrio prod dokument. Zato je ispravan mehanizam **`<meta http-equiv>`** tag — jedini pouzdan za file://-učitanu stranicu.

## Šta je urađeno
1. **`vite.config.ts`** — `cspMetaPlugin` (`apply: "build"`) ubacuje strogi CSP `<meta>` u `dist/index.html` samo pri buildu (dev server netaknut, jer Vite HMR treba inline/eval/ws). Direktive:
   - `default-src 'self'`; `script-src 'self' 'wasm-unsafe-eval'` (bez unsafe-inline/eval); `style-src 'self' 'unsafe-inline'`; `img-src 'self' data: blob:`; `font-src 'self' data:`; `media-src 'self' blob: mediastream:`; `connect-src 'self' https://api.openai.com https://*.openai.com wss://*.openai.com`; `worker-src 'self' blob:`; `object-src 'none'`; `base-uri 'self'`; `frame-src 'none'`; `form-action 'none'`.
   - `connect-src` uzak: jedini eksterni egress renderera je OpenAI Realtime SDP (`src/lib/realtime.ts` → `https://api.openai.com/v1/realtime/calls`); backend ide preko IPC-a, ne direktnog fetch-a.
2. **`securitySelfTest.cjs`** — nova `checkContentSecurityPolicy(isPackaged)`. U packaged buildu čita `dist/index.html`, dekoduje HTML entitete (`&#39;`→`'`), potvrđuje prisustvo `default-src 'self'`/`script-src 'self'`/`object-src 'none'`/`connect-src` i da `script-src` nema `unsafe-eval`/`unsafe-inline`. Fail-closed u prod; dev exempt. Dodana u `runElectronSelfTestChecks`.

## Zašto meta samo u prod / zašto ne dev
Developer pokreće `npm run dev` stalno; Vite HMR treba `unsafe-inline`/`unsafe-eval` + ws. Strogi CSP u dev-u bi razbio workflow bez sigurnosne koristi (dev je lokalno/trusted). Zato je CSP build-only.
