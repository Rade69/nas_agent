🔄 Ricky Browser Bridge

Pair this extension with the Ricky desktop companion

Checking connection...
How to pair:
  1. Open Ricky's Settings panel
  2. Find "Browser Bridge" and copy the pairing secret
  3. Paste it here and click Save & Connect
  4. A green "ON" badge on the extension means it's connected

The default broker is ws://127.0.0.1:9119 — change it only if Ricky's backend runs on a different port.

Privacy: This extension only reads tab titles and URLs for listing. It never reads page content, doesn't inject scripts, and doesn't track your browsing.
